# SWYNEX Final Data Analytics Case Study

## 📊 Project Overview

This project combines three stages of data analytics completed as part of the **SWYNEX Data Analyst Internship**:

1. Data Cleaning and Preparation
2. Exploratory Data Analysis (EDA)
3. Interactive Sales Dashboard

The objective is to transform raw sales data into meaningful business insights using Microsoft Excel.

---

## 🎯 Problem Statement

Businesses need a clear understanding of their sales performance to make informed decisions. This project analyzes sales transactions to identify revenue trends, top-performing products, city-wise performance, payment preferences, and sales representative performance.

The goal is to convert raw sales data into actionable insights through data cleaning, analysis, and interactive visualization.

## 🧹 1. Data Cleaning and Preparation

The dataset was cleaned and prepared for reliable analysis.

### Cleaning Activities

- Removed duplicate transactions.
- Handled missing customer and city values.
- Addressed missing or zero quantity values.
- Standardized city, product, and payment mode labels.
- Removed unnecessary spaces from text fields.
- Corrected date and numeric data types.
- Reviewed invalid pricing values.

### Validation Results

- Duplicate Order IDs: 0
- Blank customer names: 0
- Blank cities: 0
- Invalid quantities: 0
- Invalid unit prices: 0
- Final cleaned records: 44

---

## 📈 2. Exploratory Data Analysis (EDA)

EDA was performed to understand sales performance and identify important patterns.

### Key Performance Indicators

| Metric | Result |
|---|---:|
| Total Orders | 44 |
| Total Units Sold | 124 |
| Total Revenue | AED 1,666,500 |
| Average Order Value | AED 37,875 |
| Median Order Value | AED 27,750 |

### Key Business Insights

- **Top Product:** Laptop, generating AED 780,000 in revenue.
- **Top City:** Hyderabad, generating AED 632,000 in revenue.
- **Best Performing Month:** April, generating AED 477,500 in revenue.
- **Top Category:** Electronics, generating AED 1,256,500 in revenue.
- **Leading Payment Mode:** UPI, generating AED 670,500 in revenue.
- **Top Sales Representative by Order Count:** Vikram, with 16 orders.

---

## 💡 Business Recommendations

1. **Verify unusual pricing:** Review the Laptop price recorded for order `ORD1019` against the original transaction.
2. **Investigate monthly performance:** Analyze the factors behind April's revenue peak.
3. **Improve regional understanding:** Compare Hyderabad's performance with other cities to identify opportunities.
4. **Monitor product categories:** Review Electronics and Furniture performance separately.
5. **Evaluate sales representatives:** Compare both revenue and order count for a balanced assessment.
6. **Maintain data quality:** Continue checking for missing values, duplicates, and inconsistent entries.
